# Orca — самостійне вивчення

Робоча папка для вивчення **Orca** (desktop IDE для паралельних AI-агентів у git worktrees)
за офіційною документацією: https://www.onorca.dev/docs. Темп — один день = одна тема.

- Програма на 15 днів, сторінки доків для кожного дня: `README.md`
- Поточний стан: `PROGRESS.md` ← **єдине джерело правди про прогрес**
- Orca в користувача встановлена.

## На початку кожної сесії

1. Прочитай `PROGRESS.md`.
2. Якщо є поточний день — прочитай `Day-N/NOTES.md`.
3. Коротко скажи, де користувач зупинився, і запитай, що робимо.

## Структура

- `Day-N/NOTES.md` — конспект дня за шаблоном `templates/NOTES.md`, файли практики поруч.
- `../sandbox/` — окремий git-репо для практики в Orca (worktrees, диффи, коміти), лежить поруч
  із цим репо: `~/Desktop/Courses/Orca/{orca-learn,sandbox}`. В Orca це два окремі проєкти.
  Експериментувати в sandbox можна вільно; репо конспектів для практики в Orca не використовуємо.
- Папки `Day-N` створюються **по ходу**, не наперед.

## Фрази-тригери

| Користувач каже | Що робиш |
|---|---|
| «починаю день N» / «наступний день» | 1. Візьми список сторінок дня з `README.md` і витягни їх текст (Tavily extract; fallback — WebFetch). 2. Створи `Day-N/NOTES.md` за шаблоном: TL;DR, «Що розібрали», практичне завдання в Orca на `../sandbox/`, self-check. 3. У `PROGRESS.md` постав 🔄 і онови блок «Зараз». 4. Коротко перекажи тему і практику. |
| «роблю практику» / «допоможи з завданням» | Веди покроково: користувач сам клікає в Orca і запускає команди, ти пояснюєш і перевіряєш вставлений вивід. Результат запиши в `NOTES.md` → «Результат практики». **Потім міні-квіз:** 3–5 запитань на концепції (джерело — Self-check і «Що розібрали»), по одному, з коротким фідбеком. |
| «закінчив день» | 1. У `PROGRESS.md` постав ✅, дату, онови лічильник і «Зараз». 2. У `NOTES.md` статус ✅. 3. Закоміть (`docs(day-N): notes, practice result, mark day N done`). Push не потрібен — remote немає. 4. Запропонуй наступний день, не створюючи його без підтвердження. |
| «де я зупинився» / «статус» | 2–3 речення з `PROGRESS.md`. |

Якщо сенс фрази той самий — дій відповідно, не перепитуй формулювання.

## Git

- Гілка `main`, remote немає. Коміт — тільки при «закінчив день» або на явне прохання.
- Conventional Commits англійською: `docs(day-N): ...`, `chore: ...`.
